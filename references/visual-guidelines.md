# Visual guidelines

- Use a 16:9 landscape canvas unless the user requests a journal page ratio.
- Keep hierarchy: title, stage/module headers, node labels, annotations.
- Use 2–4 accent colors plus neutral fills; do not encode meaning by color alone.
- Prefer solid borders, modest corner radii, consistent line widths, and simple effects for Google Slides portability.
- Use common Latin and CJK fonts; record substitutions.
- Always set text colour explicitly (theme text colour, e.g. `1F2937`). Never rely on the
  PowerPoint default: an unset colour resolves to the *light* theme colour and the label
  disappears against a light fill, with no error raised at generation time.
- Keep node text short and leave space for connectors.
- Route feedback loops along an empty band (below or beside the grid) as orthogonal segments so
  a back-edge never crosses a module box.
