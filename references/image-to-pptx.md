# Image to PPTX conversion

> **声明：图片转 PPT 不保证 100% 自动还原。**
> 每次转换都必须输出「原生重建区域」和「嵌入图片区域」两份清单，缺一不可。
> 隐瞒还原程度、用整页截图冒充可编辑图，是本 skill 的禁止行为。

## 0. 门禁

进入本流程前，`figure_contract.yaml` 中 `approved` 必须为 `true`。
`approved: false` 时不得生成最终 PPTX，也不得输出最终图片。见 `confirmation-template.md`。

## 1. 分区识别（七步）

对输入图片按以下顺序处理，每步都要留下可追溯的记录：

1. **整图定性**：判断图片属于哪一类 —— 矢量风格流程图 / 位图截图 / 含照片的组图 / 数据图表 / 混合。
2. **区域切分**：把图面切成互不重叠的候选区域（模块框、箭头带、文字块、图例区、图片区、标题区）。
3. **内容归类**：每个区域标注为 `rebuild` / `embed` / `drop` 三选一（判定规则见第 2 节）。
4. **文字提取（OCR）**：对 `rebuild` 区域做文字识别；记录每条文字的原文、置信度、包围盒。
5. **结构识别**：识别箭头方向、连线走向、模块边界、包含关系、反馈回路。
6. **歧义标注**：无法判定的区域一律标注 `uncertain`，**不得猜测填充**。
7. **生成清单**：产出区域清单 + 编辑性报告，交用户确认后再落盘 PPTX。

## 2. 区域判定规则

| 区域类型 | 判定条件 | 处理方式 |
|---|---|---|
| `rebuild` | 纯色/渐变填充的几何块、可枚举的文字、规则箭头与连线、图例 | 用原生形状 + 独立文本框 + 原生连接符重建 |
| `embed` | 照片、显微图、电镜图、扫描件、复杂科学曲线、渐变网格、艺术字、手绘笔迹 | 裁剪后作为图片嵌入，保留原始分辨率 |
| `drop` | 水印、页眉页脚、期刊 logo、无关装饰 | 丢弃，并在报告中列出 |
| `uncertain` | 置信度不足、边界模糊、文字无法识别 | 默认按 `embed` 处理，并列入确认清单 |

判定优先原则：**宁可 `embed`，不可错 `rebuild`。** 把一张复杂科学曲线强行画成形状会破坏数据保真度，这是更严重的错误。

## 3. OCR 规则

- 记录每条识别结果的置信度；**低于 0.8 的必须列入确认清单**，不得直接写入 PPTX。
- 中英混排时分别标注语种，字体按 `theme.yaml` 的 `latin` / `cjk` 分别设置。
- 上下标、希腊字母、化学式（如 `H₂O`、`α-Fe₂O₃`）是 OCR 高错误区，必须逐条让用户确认。
- 无法识别的文字保留原区域为 `embed`，不要留空白文本框。

## 4. 箭头与连线识别

- 必须识别出**方向**（单向 / 双向）与**端点归属**（从哪个模块到哪个模块）。
- 无法判定端点的连线标注 `uncertain`，在确认清单中列出，由用户指定。
- 重建时使用原生连接符，并补 `a:tailEnd` 箭头（见 `PYTHON_PPTX_GUIDE.md` 的已知限制）。
- 曲线连线可用 `MSO_CONNECTOR.CURVE`，但优先用直角折线，Google Slides 兼容性更好。

## 5. 无法识别时的确认清单

出现以下任一情况，**停下来问用户**，不要自行决定：

- 区域类型判定置信度不足
- OCR 置信度 < 0.8，或出现上下标 / 希腊字母 / 化学式
- 箭头方向或端点归属不明
- 模块之间存在隐含的包含关系但边界不清
- 原图分辨率过低（< 150 dpi）导致细节不可辨
- 图中存在多个子图（a / b / c 面板）但用户未说明要转换哪几个

确认清单格式：

```yaml
uncertain_regions:
  - id: r7
    bbox: [412, 88, 690, 150]
    reason: "OCR confidence 0.62; possible subscript in 'H2O'"
    proposed: embed
```

## 6. 编辑性报告（每次转换必须输出）

落盘 PPTX 的同时，输出 `output/<name>_editability.md`，内容包含：

1. **概览**：原图尺寸、区域总数、分辨率
2. **原生重建区域清单**：id、类型、文字内容、位置 —— 这些是用户可以自由编辑的部分
3. **嵌入图片区域清单**：id、原图裁剪范围、为什么不能重建
4. **丢弃区域清单**：id、丢弃理由
5. **未确认区域清单**：id、需要用户回答的问题
6. **可编辑度评分**：`可编辑形状数 / (可编辑形状数 + 嵌入图片数)`，并给出文字结论
   - ≥ 0.8：`高度可编辑`
   - 0.5–0.8：`部分可编辑`
   - < 0.5：`主要为嵌入图片，建议改用 re-draw 模式`

报告里必须写清一句人话：*"本图共 N 个区域，其中 M 个已重建为可编辑形状，K 个仍为嵌入图片。"*

## 7. 禁止事项

- 禁止用整页截图代替流程结构（这是本 skill 的红线）
- 禁止把 `embed` 区域谎报为 `rebuild`
- 禁止在 `approved: false` 时输出最终文件
- 禁止对低置信度 OCR 结果做"看起来合理"的修补
