# Prompt Library

Prompts are grouped by pipeline stage; each maps to a contract in `references/`:

| Stage | Prompt focus | Contract |
|---|---|---|
| Journal figure analysis | layout, palette, typography (style only) | `references/reference-image-analysis.md` |
| Scientific logic extraction | entities, stages, dependencies, loops | `references/workflow-contract.md` |
| Confirmation stage | seven-part draft, approval gate | `references/confirmation-template.md` |
| Figure architecture | reading direction, grouping, hierarchy | `references/visual-guidelines.md` |
| PowerPoint object tree | nodes, labels, connectors | `references/workflow-contract.md` |
| Image-to-PPTX conversion | region classification, editability report | `references/image-to-pptx.md` |
| Quality checking | editability + visual QA | `references/validation-rules.md` |
